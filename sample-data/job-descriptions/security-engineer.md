# Security Engineer — Information Security

**Level:** L5
**Department:** Information Security
**Reports to:** Chief Information Security Officer

## Role Summary

The Security Engineer protects the company's systems, data, and customers by
building secure infrastructure, hunting for vulnerabilities, and responding to
threats. The role blends hands-on engineering with security operations.

## Key Responsibilities

- Design and maintain security controls across cloud and application layers.
- Run vulnerability assessments and coordinate remediation with engineering teams.
- Build detection and response tooling; participate in the on-call rotation.
- Lead secure-by-design reviews for new services and third-party integrations.
- Support compliance efforts (SOC 2, ISO 27001) with evidence and controls.

## Required Background

- 4+ years in security engineering or a related infrastructure role.
- Hands-on experience with cloud security on AWS, including IAM and network controls.
- Familiarity with SIEM, IDS/IPS, and incident response workflows.
- Scripting proficiency in Python or Go.

## Everyday Expectations

- Triage security alerts and drive incidents to resolution.
- Partner with engineering to shift security left in the development lifecycle.
- Keep the threat model and runbooks current.
